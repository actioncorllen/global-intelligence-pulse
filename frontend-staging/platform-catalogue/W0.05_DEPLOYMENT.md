## Requirement coverage (16)
1. **Final source-code changes** — the 8 files above; one parent-page import swap.
2. **Actual RPC signatures / TS contracts** — validated (see table below); decode-only, strict null handling.
3. **Existing component integration** — reuses `EcommerceWorkspace`, `ECOMMERCE_WORKSPACE_QUERY_KEY`, supabase singleton.
4. **Shared Catalogue / My Research switching** — `CatalogueWorkspace` segmented `Tabs`.
5. **18-market country selector** — `CatalogueCountrySelector`, `APPROVED_MARKETS` (full universe), data-presence from `fn_catalogue_browse_markets`.
6. **Truthful opportunity classifications** — `classifyBand` renders the **confidence-floored** band (W0.04); advertising-only cards read *Insufficient evidence*, never a high-test label.
7. **Advertising/demand/competition/supplier evidence** — card shows band + decision + confidence + score + coverage + source; backend keeps advertisers≠sellers and UNKNOWN≠0.
8. **UNKNOWN / missing-data states** — `showNumber`/coverage/category render `Unknown` (never 0); image placeholder when no authorized media.
9. **Freshness & source attribution** — `showFreshness` (stale flagged) + `sourceProvider`.
10. **Country-specific pricing & indicators** — market + currency on every card; cross-market reference prices labelled, never shown as local fact.
11. **Authorized image / placeholder** — image rendered only when `imageState === "AUTHORIZED"` with a ref; else neutral placeholder.
12. **Save / Find via adoption** — `useSaveFromCatalogue` adopts then calls `save_own_product` (existing path).
13. **Optional deeper research with plan allowance** — `useResearchFromCatalogue` adopts then calls `fn_own_request_product_market_research`; surfaces `ALLOWANCE_BLOCKED`/`CACHE_REUSED` (metered, W0.02).
14. **Loading / error / empty-market / rights-revoked states** — `CatalogueWorkspace` renders each; withdrawn (rights-revoked) items simply don't appear (server read-time revocation), explained in the empty copy.
15. **Tenant security & entitlement** — all reads/writes are RPCs; entitlement + tenant isolation enforced server-side; no tenant id or provider logic client-side.
16. **Responsive & accessibility** — responsive grid (`sm/lg/xl` columns); selector has `aria-label`; `<img alt>`; lazy images; semantic `<dl>` for metrics.
