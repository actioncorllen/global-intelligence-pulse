## 2. Provider discovery + capability verification
`n8n list_n8n_gateway_services` reports `video: [textToVideo, imageToVideo]` for **MiniMax** (`minimaxApi`)
and **Alibaba/Qwen Wan** (`alibabaCloudApi`) — both Gateway-managed (usage-based). OpenAI exposes only
`video:[generate]` (text→video/Sora), **not** image→video. Node type inspection confirmed real capability:
- MiniMax `imageToVideo`: models incl. `MiniMax-H3` (4–15s, 768P/2K) but **no prompt steering** for H3; other
  models cap at 6/10s.
- **Alibaba/Qwen Wan `imageToVideo`**: continuous **2–15s**, 720P/1080P, **prompt-steerable**, single/multi
  shot — meets 10–15s in one clip AND lets the canonical-intelligence storyboard steer motion.

from the source frame, the dispatch contract instructs the executor to prepare a 1080×1920 source frame
(pad/crop, no baked text) before the i2v call so the delivered clip is natively vertical.
